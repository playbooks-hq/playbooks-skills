# Publish from the source

Resolve the owning Workspace, source kind and exact source ID. For Chats, Agents and Projects, enable the `templates` toolset alongside existing groups and inspect the matching draft tool. Read the draft first. Create one only for an authorized authoring request. Discover owned listings with `playbooks_workspace_templates` and inspect the selected listing with `playbooks_workspace_template`.

Read `playbooks_workspace_template_source` and summarize the package, exclusions, client-specific material, and setup the recipient must complete. Review visibility, listing details and revision with the publisher. Save requested listing edits with `playbooks_workspace_template_update`. With explicit approval to publish that reviewed package, call `playbooks_workspace_template_publish` with confirmation. On a revision conflict, inspect the changed source before proceeding. Verify the resulting version with `playbooks_workspace_template_versions` and read back listing visibility. Report the listing ID, published version and visibility.

For Workflows and Workspaces, open the source’s Settings → Marketplace in the app for authoring. Review included resources, dependencies, unresolved setup and redistribution authority. Check the resulting listing and version after publication. Workspace policy and source permissions apply.
