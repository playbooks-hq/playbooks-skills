description: Connect an editor to Playbooks, discover authorized Workspaces, or choose a Playbooks resource for a new developer task. Use for onboarding and questions about how Playbooks works.

Read [the resource model](references/resource-model.md) when selecting a destination and [the MCP guide](references/using-playbooks-mcp.md) when connecting or inspecting access.

For a first read, verify the connection with playbooks_status, list authorized Workspaces, and ask the developer to select one if necessary. Call playbooks_projects with its explicit workspace ID and report the Projects returned. If the list is empty, report that observation. For planning questions, explain which resource owns the requested work and what result the developer should expect.
